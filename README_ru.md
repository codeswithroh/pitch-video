# Pitch Video

### Запишите, как вы читаете свой питч. Агент превратит это в демо-ролик, готовый к запуску.

Заявки на хакатоны, ролики к запуску и демо для инвесторов требуют одного и того же: **вы объясняете, а продукт говорит сам за себя.** Вручную это часы в видеоредакторе: вырезать «э-э», подгонять кадры под каждую фразу, делать субтитры, искать звуковые эффекты — и в конце обнаружить, что губы расходятся со звуком на 300 мс.

**Pitch Video — это навык (skill) для агента, который берёт на себя весь монтаж.** Отдайте агенту запись (а также сценарий и приложение, если они есть). Он расшифрует речь, вырежет паузы, ускорит вас до 1.1× без эффекта бурундука, снимет ваш продукт скриптованным браузером, привяжет каждый кадр точно к произнесённому слову и добавит субтитры, кружок с лицом, анимированную схему, кинематографичные звуковые эффекты и фоновую музыку с дакингом. А потом **сам измерит результат** (липсинк, дрейф звука, громкость, разборчивость голоса) и откажется отдавать вам битый файл.

Всё работает локально на ffmpeg, whisper.cpp и Playwright. Никаких загрузок, подписок и таймлайнов.

## Быстрый старт

### 1. Установите навык

```bash
npx skills add codeswithroh/pitch-video
```

или напрямую для Claude Code:

```bash
curl -fsSL https://raw.githubusercontent.com/codeswithroh/pitch-video/main/install.sh | bash
```

Установщик копирует навык в `~/.claude/skills/pitch-video` (и в `~/.agents/skills/pitch-video` для других агентов) и собирает общий набор инструментов: Python venv, Playwright Chromium, модель Whisper `small.en` и модель ключевых точек лица. После установки перезапустите агента.

### 2. Запишите себя

Прочитайте сценарий в камеру. Горизонтально, лицо и плечи в кадре, тихая комната. Делайте вдох между разделами. Оговорились — ничего страшного, просто перечитайте строку.

> Нужен сценарий? Попросите агента: *«Напиши мне двухминутный сценарий питч-видео для этого репозитория по сюжетной структуре pitch-video».*

### 3. Попросите агента

```text
Make a pitch video from ~/Movies/my_pitch.mov.
The script is docs/pitch-script.md and the app runs at http://localhost:5173.
```

Агент спланирует сцены по тому, что вы сказали, снимет приложение, отрендерит, проверит и отдаст вам `out/demo.mp4`, а также облегчённый `demo_small.mp4` для загрузки.

| **Обрезка пауз** | Вырезает тишину, сохраняя естественные вдохи, с более длинными паузами на сменах сцен и там, где вы их задали ("Until now." … *пауза*). |
| **Темп 1.1×** | Более плотная подача без изменения высоты голоса. Картинка и голос ускоряются вместе, поэтому синхрон остаётся точным. |
| **Склейки по словам** | Каждая сцена и кадр привязаны к *фразе, которую вы произносите*, поэтому картинка меняется ровно на той реплике, которая её вводит. |
| **Скриптованная съёмка продукта** | Генерирует сценарий съёмки Playwright для вашего приложения: Chrome с окном, CDP-скринкаст на 30 fps и журнал событий с метками времени для монтажа. |
| **Кружок с лицом** | Автоматическое кадрирование по ключевым точкам лица, скруглённые углы, акцентная рамка. Скрывается на полноэкранных кадрах и финальной карточке. |
| **Правильные субтитры** | Тайминги Whisper по фрагментам, затем пословное выравнивание по сценарию: "Virev" становится **VRF**, а `**bold**` в сценарии — выделенными словами. |
| **Поясняющие анимации** | HTML-схемы, шаги которых привязаны к вашему рассказу (`CUES.find(c => /sealed/.test(c.text))`). |
| **Кинематографичный звук** | 23 синтезированных SFX (riser, boom, whoosh, lock, chime, glitch…), автоматически расставленных на склейках и карточках и приглушённых под каждым сказанным словом. Фоновая музыка по желанию. |
| **Контроль качества** | Замер липсинка, проверка A/V-дрейфа, аудит декодированных сэмплов, дБ голоса над фоном для каждой реплики, громкость EBU R128 и контактный лист. Отдаёт результат только при `PASS`. |

## Как это работает

<img src="docs/assets/pipeline.svg" alt="Пайплайн: на входе ваше видео, сценарий и продукт; навык выравнивает, расшифровывает, обрезает, снимает, монтирует, накладывает, озвучивает и проверяет; на выходе demo.mp4" width="100%" />

Весь монтаж живёт в одном читаемом файле — `project.json`. Сцены начинаются с фраз, кадры переключаются на фразах, а звуковые эффекты срабатывают на фразах или на записанных событиях приложения:

```jsonc
{
  "speed": 1.1,
  "scenes": [
    { "title": "The hook", "start": "Every onchain game", "shots": [
      { "speaker": true },
      { "from": "If it lives", "rec": "main", "t": 9.8 } ]},
    { "title": "The problem", "start": "fog of war", "shots": [
      { "rec": "main", "t": 18.8, "card": "problem" },
      { "from": "Until now", "title": "UNTIL NOW." } ]},
    { "title": "How it works", "start": "Every position is sealed", "shots": [{ "anim": "diagram" }] }
  ],
  "sfx": [{ "sound": "denied", "phrase": "null", "edge": "end", "offset": -0.4 }]
}
```

Смотрите полный [справочник по project.json](docs/project-json.md) и [разбор пайплайна](docs/pipeline.md).

## Почему получается с первого раза

Этот навык вырос из реального монтажа, который потребовал множества мучительных итераций. Каждая ошибка стала правилом, которое навык теперь соблюдает:

- **«Губы не совпадают».** В файлах QuickTime и с телефона звук часто начинается примерно на 150 мс позже видео. Навык явно выравнивает их прежде всего остального.
- **«Синхрон уплывает ближе к концу».** Склейки ложатся на сетку кадров 30 fps — по номеру кадра *и* соответствующему номеру аудиосэмпла. Ничего не накапливается.
- **«Голос обрывается раньше, чем рот».** Один объединённый граф ffmpeg молча терял 9 секунд аудиосэмплов (loudnorm выдаёт 192 кГц). Теперь картинка и звук рендерятся отдельными проходами, каждая ветка ресемплируется в 48 кГц, а проверка декодирует итоговый файл, чтобы подтвердить число сэмплов.
- **«Субтитры запаздывают».** Метки времени Whisper по целому файлу отстают. Расшифровка по фрагментам ставит субтитры точно на границы речи.
- **«Эффекты заглушают голос».** Звуковые эффекты приглушаются на −9 дБ под каждой репликой, тяжёлые удары пропускаются через ФНЧ, если задевают речь, а финальный бум звучит *после* вашего последнего слова.
- **«Картинка мыльная».** Встроенный рекордер Playwright — это VP8 с низким битрейтом. Навык использует CDP-скринкаст из Chrome с окном и включённым GPU.

Полный список — в [docs/lessons.md](docs/lessons.md).

## Требования

- macOS или Linux с `ffmpeg`, `whisper-cli` (whisper.cpp), Node.js 18+ и Python 3.10+.
- macOS: `brew install ffmpeg whisper-cpp node python`
- Около 1 ГБ на диске для набора инструментов (Chromium, модель Whisper, venv), общего для всех проектов.

## FAQ

<details>
<summary><strong>Какие агенты могут его использовать?</strong></summary>

Любой агент, который загружает навыки `SKILL.md` и умеет выполнять команды в шелле: Claude Code, Codex, Cursor, Gemini CLI и другие через `npx skills add`. Скрипты — это обычные Python, Node и ffmpeg, так что [пайплайн можно запустить и вручную](docs/pipeline.md).

</details>

<details>
<summary><strong>У меня нет сценария. Всё равно сработает?</strong></summary>

Да. Субтитры берутся прямо из Whisper, а агент их вычитывает. Сценарий лишь делает термины и названия продуктов точными и позволяет выделять акценты через `**bold**`.

</details>

<details>
<summary><strong>Мой продукт — не веб-приложение.</strong></summary>

Подойдёт любой материал: запись экрана, захват с симулятора или изображения. Положите кадры в `shots/<name>/` вместе с `stamps.json` или используйте кадры типа `image`. Шаблон веб-съёмки — это удобство, а не требование.

</details>

<details>
<summary><strong>Можно использовать свою музыку?</strong></summary>

Укажите `"music": "path/to/track.mp3"`. Трек зацикливается, нормализуется на низкую громкость и приглушается сайдчейном под вашим голосом. Для тишины используйте `"none"`.

</details>

<details>
<summary><strong>Вертикальное видео для TikTok, Reels или Shorts?</strong></summary>

Пока нет: на выходе 1920×1080. Формат 9:16 — первый пункт в [роадмапе](CHANGELOG.md#roadmap).

</details>

<details>
<summary><strong>Что-нибудь загружается в сеть?</strong></summary>

Нет. Расшифровка, рендеринг и анализ работают на вашей машине. Агент видит расшифровку и таймлайн, а у его провайдера модели своя политика обработки данных.

</details>
